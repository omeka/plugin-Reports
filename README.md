# Reports

The Reports plugin for Omeka Classic gives administrators the ability to create reports of Omeka items.

Reports can produce an HTML list or PDF containing QR codes, and can be customized to produce other report formats.

See the [Reports page in the Omeka Classic user manual](https://omeka.org/classic/docs/Plugins/Reports) for user documentation.
